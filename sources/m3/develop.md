## Material platforms

The Material Compose library is built in-house, so it receives the latest Material updates first. It’s the recommended platform for developing on Android.

_footer: Jetpack Compose is the recommended toolkit for building Material UI on Android. Get developer documentation, tutorials, and feature highlights to build with Material for Android using Jetpack Compose._
_link: https://m3.material.io/develop/android/jetpack-compose_

The Material Flutter library is actively maintained by the Flutter team and receives periodic Material updates.

_footer: Flutter offers the best Material support for multi-platform app development. Get developer documentation to build with Material for Flutter._
_link: https://m3.material.io/develop/flutter_

### Additional platforms

Material’s Android Views (MDC-Android) and web libraries are in maintenance mode. They’re still available to use, but are not receiving feature updates from Material.

_footer: Developer documentation to build with Material for Android Views._
_link: https://m3.material.io/develop/android/mdc-android_

_footer: Developer documentation to build with Material in any web framework._
_link: https://m3.material.io/develop/web_
