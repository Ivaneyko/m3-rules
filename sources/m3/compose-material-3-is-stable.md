# Compose Material 3 1.5.0 is stable

> Includes expressive components, theming, improved accessibility, and more

slug: compose-material-3-is-stable  |  updated: 2026-11-18T20:00:54.575Z

<!-- section: Tab 1 -->

_footer: **Material Android**_

With the release of [Compose Material 3 version 1.5.0](https://developer.android.com/jetpack/androidx/releases/compose-material3#1.5.0) and [Jetpack Compose 1.13](https://goo.gle/compose-blog-nov-2026), Material 3 core and Expressive APIs graduated to stable. This milestone gives you a complete, production-ready design system for building modern, expressive UIs in Jetpack Compose.

As Material 3 enters its [sixth year of availability](https://m3.material.io/blog/announcing-material-you), the Compose Material 2 library is no longer actively maintained. We recommend [migrating from Material 2 to Material 3](https://developer.android.com/develop/ui/compose/designsystems/material2-material3) to get the latest bug fixes and design language for Android.

## What’s new

### Compose Material 3 1.5.0

Compose Material 3 version 1.5.0 promotes most M3 experimental APIs to stable, and includes improved [M3 Expressive](https://m3.material.io/blog/building-with-m3-expressive) component behaviors, performance, expressive theming, typography, accessibility, and keyboard navigation. Adopt M3 Expressive APIs to deliver premium Android experiences.

With this release:

-
Every core Material 2 component has a stable Material 3 equivalent, with long-standing components like app bars, search, sliders, carousels, and basic alert dialogs graduating to stable

-
New stable M3 Expressive components include split buttons, button groups, shape-morphing toggle buttons and chips, floating toolbars, wavy progress indicators, nested menu and segmented list items

-
Expressive color schemes, shapes, and motion are now stable, and you can set a custom brand font across the entire type scale at once

-
Accessibility and keyboard navigation are improved, with updated focus order and keyboard support across date pickers, time pickers, sliders, scaffolds, and navigation components

See all the new features in action in the [Compose Material 3 catalog](https://play.google.com/store/apps/details?id=androidx.compose.material.catalog). For the full list of changes, read the [Compose Material 3 version 1.5.0 release notes](https://developer.android.com/jetpack/androidx/releases/compose-material3#1.5.0).

### Jetpack Compose 1.13 release

Alongside the Compose Material 3 release, Jetpack Compose version 1.13 is also rolling out as stable. Compose 1.13 makes UI development easier and more expressive with a new performance analysis skill, stable flexbox and grid layouts, native progressive blur, custom failure handling in UI tests, and more.

[Read more about Jetpack Compose 1.13](https://goo.gle/compose-blog-nov-2026)

## Migrate to Compose Material 3 today

With all core Material 2 equivalents and Material 3 Expressive components now production-ready, there’s no reason to wait to make the switch. The Compose Material 2 library (androidx.compose.material) is deprecated and no longer actively maintained.

#### Why migrate now?

-
Every core Material 2 component now has a stable Material 3 equivalent

-
You get access to Material 3 Expressive components, theming, and motion

-
Material 3 receives ongoing accessibility improvements and bug fixes

#### Still using Material 2?

Follow our guide to [migrate from Material 2 to Material 3](https://developer.android.com/develop/ui/compose/designsystems/material2-material3).

#### Still building with Material Views?

[Material Views is in maintenance mode](https://m3.material.io/blog/material-is-compose-first). Now’s the time to [migrate to Jetpack Compose](https://goo.gle/compose-migration). Get started by migrating your apps screen-by-screen with the [migration Android skill,](https://github.com/android/skills) which you can use with Android Studio, Android CLI, or any other AI tool.
